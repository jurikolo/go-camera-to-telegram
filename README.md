# Go IP Camera Scanner & Telegram Bot - Implementation Roadmap

## Project Overview
A Go application that discovers IP cameras on a local network (port 554), captures images, and sends them to Telegram. Optimized for Raspberry Pi 4 with Raspbian OS.

## Prerequisites
- Go 1.21+ installed on Raspberry Pi 4
- Telegram Bot Token (from @BotFather)
- IP cameras supporting RTSP (port 554)
- Network access to cameras
